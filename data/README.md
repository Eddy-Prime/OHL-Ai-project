# Data Directory

Place all required training CSV files in this folder:

- `gold_match.csv`
- `gold_match_tickets.csv`
- `gold_match_context.csv`
- `gold_google_trends_daily.csv`
- `gold_belga_press_articles.csv`
- `gold_match_goals.csv`

The codebase uses only repository-relative paths (`PROJECT_ROOT / "data"`).
